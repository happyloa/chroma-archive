## 1. 背景與目標

Pantone 從 2000 年開始每年公布一個「年度代表色」（Color of the Year，以下簡稱 COTY），2016 和 2021 年各公布兩色。2026 年度色是 PANTONE 11-4201 Cloud Dancer，也是這個計畫第一次選白色。2027 年度色預計在 2026 年 12 月初公布。

這個網站把 2000 到 2026 年的年度色整理成可瀏覽的典藏，並為每個顏色提供產品設計發想：適合的產品類型、材質與表面處理、配色組合，以及可以即時換色的 3D 產品預覽。視覺目標是 Awwwards 等級的作品集網站：大量留白、編輯排版、WebGL 場景與平滑的捲動敘事。

### 目標

1. 讓訪客在 10 秒內看到當年度色，並理解它是哪一年、哪個色號。
2. 讓訪客用時間軸瀏覽歷年色票，任一年份兩次點擊內可到達。
3. 讓設計師在每個顏色的頁面拿到可直接用的設計參考：色值、配色、CMF（Color, Material, Finish）建議、產品概念。
4. 網站本身能當作作品集展示，具備 Awwwards 投稿的完成度。

### 非目標

- 不提供官方色彩標準或印刷用色值。
- 不做會員、收藏、留言等需要後端狀態的功能（第一版）。
- 不販售或連結 Pantone 商品。

## 3. 資訊架構

```
/                       首頁：當年度色 Hero + 捲動敘事 + 時間軸入口
/archive                歷年典藏：3D 色票時間軸
/years/[year]           年度頁：色彩故事、色值、配色、設計發想
/years/[year]/lab       產品實驗室：3D 產品換色、材質、配色
/space                  色彩空間：所有年度色放進 3D OKLCH 色彩空間
/about                  關於、資料來源、非官方聲明
/404                    找不到頁面（顯示隨機年度色）
```

英文版放在 `/en/` 前綴下（P2，見第 6 節）。

## 4. 使用者故事與驗收條件

優先度：P1 是第一次上線必備，P2 是上線後一個月內，P3 是有餘力再做。

### US-01 首次進站看到當年度色（P1）

身為第一次來的訪客，我想一進站就看到今年的年度色，知道這個網站在做什麼。

驗收條件：

1. 預載畫面從 2000 數到當年，數字旁的色塊依序切換成各年度色，總長不超過 2.2 秒；第二次造訪（sessionStorage 有記錄）直接跳過。
2. Hero 全螢幕顯示當年度色的 WebGL 場景，標題顯示色名、色號、年份。
3. 往下捲動時，標題逐字拆開淡出，畫面轉進「年度色故事」段落。
4. 開啟「減少動態效果」時，略過預載動畫，Hero 換成靜態漸層。

### US-02 用時間軸瀏覽歷年色票（P1）

身為瀏覽者，我想沿著時間軸看完 2000 到 2026 年的顏色，感受色彩潮流的變化。

驗收條件：

1. `/archive` 以 3D 場景呈現所有年份的色卡，色卡造型參考實體色票（上半部色塊、下半部白底標籤寫年份與色名）。
2. 滑鼠滾輪、觸控拖曳、鍵盤左右鍵都能沿時間軸移動；移動有慣性。
3. 目前聚焦的年份，背景會被它的顏色渲染，其他色卡退後並降低飽和度。
4. 雙色年份（2016、2021）以一張雙色卡呈現。
5. 點擊色卡進入年度頁，色卡放大成年度頁的 Hero（共享元素轉場）。
6. 時間軸下方有一條 2D 年份刻度列，可直接點年份跳轉，螢幕閱讀器讀得到每一年。

### US-03 查看單一年度色的詳細資訊（P1）

身為設計師，我想在年度頁拿到這個顏色的完整資訊。

驗收條件：

1. 顯示色名（英文原名、中文譯名）、色號、公布日期。
2. 顯示 HEX、RGB、HSL、OKLCH、CIELAB 近似值，每個值都能一鍵複製，複製後有提示。
3. 顯示一段自行撰寫的色彩故事（300 到 500 字），內容說明 Pantone 公布時的定位與當年的社會、設計脈絡。
4. 顯示五組配色：互補、類似、三角、分裂互補、單色漸層，每組 3 到 5 色，可複製全部色值或下載 `.ase`（P2）與 CSS 變數檔。
5. 顯示「與相鄰年份比較」：前一年、後一年的色塊與 OKLCH 差距。
6. 色值區旁標註「螢幕近似色，非官方色彩標準」。

### US-04 取得產品設計發想（P1）

身為產品設計師，我想直接看到這個顏色用在實際產品上的樣子，知道它適合什麼產品、搭什麼材質。

設計發想的主體是 3D 產品模型，文字是輔助說明。

驗收條件：

1. 每個年度頁有「設計發想」段落，以 3D 產品展示為主：
   - 3 個產品概念，每個都是一個套用該概念 CMF（主色、輔色、材質、表面處理）的 3D 模型，可以拖曳旋轉。
   - 捲動到這個段落時，模型依序進場；同一時間只有畫面中的模型在 render，其餘暫停。
   - 模型旁附名稱、產品類別、一句話描述、目標使用者與 CMF 說明。
2. 適合與不適合的材質各 3 種，附理由；4 到 6 個情緒關鍵字。
3. 每個產品概念可以一鍵進入產品實驗室，帶入同樣的設定繼續調整。
4. 不支援 WebGL 或開啟減少動態效果時，改顯示預先算好的靜態產品圖。
5. 內容由人工撰寫或審稿（可用 AI 起稿），不放未經審閱的生成文字。

### US-05 在產品實驗室試色（P1）

身為產品設計師，我想把年度色套到 3D 產品模型上，換材質看效果，截圖放進提案。

驗收條件：

1. 至少提供 6 種產品模型：單椅、耳罩式耳機、陶瓷花瓶、智慧音箱、桌燈、運動鞋。
2. 可切換 6 種表面處理：霧面、緞面、亮面、金屬、絨布、半透明。
3. 可指定主色與輔色；主色預設為年度色，輔色從該年配色中挑，也可以換成任一年度色。
4. 模型可旋轉、縮放，有 3 種燈光預設（攝影棚、自然光、夜間）。
5. 「匯出圖片」產生 2048 × 2048 PNG，右下角浮水印標註年份、色名與網址。
6. 目前的設定寫進網址查詢參數，複製網址就能分享同一個畫面。
7. 不支援 WebGL 時，顯示預先算好的靜態產品圖。
8. 情境場景：除了純色攝影棚，另有客廳、臥室、辦公室三個場景。產品放在場景中合理的位置（例如單椅在客廳地毯上、桌燈在辦公桌上），場景家具只用中性色與木頭、金屬等材質，不搶年度色。切換場景時鏡頭與燈光平滑過渡。
9. 互動：
   - 點選產品零件可以直接指定要換色的部位（主色區或輔色區），滑鼠懸停時零件會微微發亮。
   - 鏡頭預設：正面、側面、俯視、特寫，切換時鏡頭平滑移動。
   - 自轉可以開關；開啟減少動態效果時預設關閉。
   - 換產品時新模型落下進場；換顏色與表面處理以約 0.4 秒漸變。減少動態效果時直接切換。
10. 場景與鏡頭也寫進網址參數。

### US-06 在色彩空間中比較所有年度色（P2）

身為色彩愛好者，我想看 27 年的顏色在色彩空間裡怎麼分布。

驗收條件：

1. `/space` 以 OKLCH 圓柱座標放置所有年度色（角度＝色相，半徑＝彩度，高度＝明度），每個顏色是一顆球。
2. 可切換排列方式：色彩空間、時間螺旋、依色相排列的色環；切換時球體以動畫移到新位置。
3. 懸停顯示年份與色名，點擊進入年度頁。
4. 有一份對應的 HTML 表格，列出所有年度色的 OKLCH 值，可依欄位排序。

### US-07 頁面轉場（P1）

身為訪客，我希望換頁時畫面連續，不會整頁閃白。

驗收條件：

1. 站內換頁使用目的頁的年度色做液態擴散轉場，時長 0.8 到 1.2 秒。
2. WebGL canvas 在換頁時保留，不重新建立 renderer。
3. 瀏覽器上一頁、下一頁行為正常，捲動位置會還原。
4. 減少動態效果時改為 200 毫秒淡入淡出。

### US-08 新增下一年度色（P1，維運）

身為網站維護者，我想在 Pantone 公布新年度色當天就上線。

驗收條件：

1. 只修改 `data/colors.json` 和新增 `src/content/years/[year].md` 就能完成，不需改程式。
2. 建置時自動算出衍生色值、配色、對比文字色、OG 圖。
3. 資料格式錯誤時建置失敗，錯誤訊息指出哪一年的哪個欄位。

### US-09 分享到社群（P2）

驗收條件：

1. 每個年度頁有專屬 OG 圖（1200 × 630），在建置時產生。
2. 頁面有正確的 `<title>`、description、canonical、hreflang（雙語上線後）。

### US-10 深淺色切換（P1）

身為訪客，我想依環境切換深色或淺色介面。

驗收條件：

1. 頁首有切換按鈕；第一次造訪時跟隨系統的深淺色設定，切換後記住選擇（localStorage），換頁與重新整理都維持。
2. 首次繪製前就套用主題，不出現錯誤配色的閃爍。
3. 切換時從按鈕位置以圓形擴散揭露新配色，約 0.8 秒；動畫進行中頁面仍可操作。做法參考作者作品集網站：把舊配色畫面複製成疊層，以 CSS mask 挖出擴大的圓。WebGL 畫面先存成快照放進疊層。
4. 減少動態效果或強制色彩模式時直接切換，不播動畫。
5. 年度色本身、實體色票卡片（白色標籤紙）、淺色年份的深色 Hero 不隨主題改變；3D 產品視窗的背景跟著主題換。

### US-11 上傳自己的模型（P1）

身為產品設計師，我想把自己的產品模型放進實驗室，套上年度色看效果。

驗收條件：

1. 支援 .glb、.gltf（資源需內嵌）、.obj、.stl，單檔 50 MB 以內；其他格式或 Draco 壓縮的模型顯示清楚的錯誤訊息。
2. 檔案只在瀏覽器裡解析，不上傳、不儲存到伺服器，頁面上明確告知；關掉頁面就消失。分享網址不帶上傳的模型。
3. 上傳後所有零件先套主色，點零件可以在主色與輔色之間切換；表面處理、場景、鏡頭、匯出都能照常使用。
4. 換新檔或離開頁面時釋放模型佔用的記憶體。

### US-12 場景真實感與相片級渲染（P1）

身為產品設計師，我想讓實驗室的畫面接近真實拍攝，可以直接放進提案。

驗收條件：

1. 情境場景的地板與牆面使用 PBR 貼圖，家具使用真實模型（Poly Haven，CC0），環境光使用實拍 HDRI；HDRI 載入前先以程式產生的燈箱頂替。
2. 陰影為柔和陰影（VSM），高畫質檔位使用 2048 陰影貼圖。
3. 「相片級渲染」開關：開啟後以路徑追蹤逐步累積畫面，畫面右上角顯示取樣次數；操作鏡頭、換色、換場景時重新累積。開啟時暫停自動旋轉與過渡動畫。純色背景會加上無接縫背景板，讓產品有真實的落地陰影。
4. 相片級渲染開啟時，匯出圖片以路徑追蹤累積 128 次取樣，按鈕顯示進度。
5. 沒有 GPU 加速的裝置（低畫質檔位）停用開關並說明原因。
6. 路徑追蹤套件只在第一次開啟時載入，不計入一般頁面的 JS。

## 7. 視覺與互動方向

整體氣質參考設計雜誌與藝廊網站：大字級襯線標題、嚴格網格、大量留白，畫面上的顏色只有年度色。

| 元素       | 方向                                                                                                                                     |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 字體       | 拉丁標題用可變字重的襯線體（候選：Fraunces、Instrument Serif），內文用 Inter；中文標題用思源宋體，內文用思源黑體，依頁面實際用字做子集化 |
| 版面       | 12 欄網格，桌機外距 4vw；年份數字當作視覺元素，放大到 20vw 以上                                                                          |
| 質感       | 全畫面細微底片顆粒（後製 noise），色塊邊緣有極輕微的紙張纖維                                                                             |
| Hero 場景  | 年度色的液態顏料：以 noise 驅動的流體 shader，滑鼠移動會攪動；淺色年份（例如 Cloud Dancer）改用體積雲與柔光，畫面層次來自陰影與明暗      |
| 時間軸場景 | 色卡沿 3D 樣條曲線排列，相機隨捲動沿曲線前進；聚焦色卡輕微浮起並反射環境光                                                               |
| 轉場       | 目的頁年度色從點擊位置以液態邊緣擴散填滿畫面，再退開露出新頁                                                                             |
| 文字動態   | GSAP SplitText 逐字或逐行出場；年份數字捲動時字重從 300 變到 900                                                                         |
| 游標       | 圓點游標，懸停在色塊上會吸取該色並放大                                                                                                   |

淺色年份的處理是規格的一部分：2026 Cloud Dancer、2006 Sand Dollar、2016 Rose Quartz 都很淺，Hero 與轉場不能因為顏色接近背景就看不見。做法是當顏色 OKLCH 明度高於 0.85 時，介面切換到深色底，年度色以光源和雲霧的形式出現。

## 8. 邊界情況

1. 雙色年份：資料結構允許一年有多個顏色；Hero 以兩色交融呈現，時間軸用雙色卡，產品實驗室預設主色與輔色就是這兩色。
2. 尚未公布的年份：`/years/2027` 在資料不存在時回 404，不出現空白頁。
3. 極淺或極深的顏色：依第 7 節的明度規則處理。
4. 低階裝置：GPU 等級為低時，關閉後製、DPR 上限 1、產品實驗室降為低面數模型。
5. 分頁切到背景：暫停 render loop，回來時恢復。
6. 視窗縮放：canvas 尺寸以 ResizeObserver 更新，節流 100 毫秒。
